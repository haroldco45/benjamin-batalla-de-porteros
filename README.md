# Benjamín · Campeón · Batalla de Porteros 2026

App recuerdo (PWA) de Benjamín, campeón de la categoría 2014-2015 en la Batalla de Porteros 2026 de la Academia de Porteros JuanP, en Caucasia, Antioquia. Hermana de la app de su hermano Jerónimo (https://batalla-de-porteros.netlify.app/).

**Netlify:** https://benjamin-batalla-de-porteros.netlify.app/
**Repo:** haroldco45/benjamin-batalla-de-porteros

## Qué tiene
- Portada con el guante dorado del torneo, luces y el nombre animado
- Ficha: Campeón, primer lugar, torneo, categoría 2014-2015, organizador y lugar
- El guante dorado con brillo e inclinación al tocarlo
- "Dos porteros en la familia": enlace a la app de Jerónimo
- Carta "para leer cuando seas grande"
- Mensajes de felicitación que se envían por WhatsApp a Luis, el papá
- Compartir por WhatsApp, copiar enlace, español / inglés, instalable
- Vista previa del enlace (img/og-benjamin.jpg, 1200×630)

## Publicar
Subir todo al repo y en Netlify: Add new site → Import from GitHub → este repo → nombre `benjamin-batalla-de-porteros`. Si el nombre cambia, cambiar la URL en `index.html` (etiquetas og/twitter y `URL_APP`).

La página lleva `noindex`: es un recuerdo de un niño y se comparte solo por enlace.
